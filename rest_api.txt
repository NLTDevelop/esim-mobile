

1. Авторизація apple.
Потрібен запит на валідацію identity token епла для повної реалізації apple авторизації.
Запит має бути наступним: POST з body:
{
    "access_token": "мій епл токен"
}

В результаті отримаю те саме що і dід google авторизації

2. Потрібно пофіксити гугл авторизацію на стороні бекенду. Чомусь коли відправляю токен отримую 500 помилку на IOS.
На андроіді теж не можу авторизуватися, але це помилка в налаштуваннях проекту в google cloud console. Необхідно перевірити
Чи правильно введено SHA-1 ключ для Android ClienId і чи правильний Web ClientId був відправлений мені.

3. Список esim користувача

Потрібен запит на список esim які вже придбав користувач.

Це має бути GET запит в якому я отримую список обʼєктів esim.

4. Наскільки розумію в запит GET /api/v1/esim/regional треба передати region_id який ми отримуюємо із запиту GET /api/v1/region, але зараз цей запит повертає 404.

5. Не розумію, чому результат запиту /api/v1/esim/local і результат запиту /api/v1/esim/regional виглядають однаково.
Можливо варто додати булеву змінну яка буде відображати чи це локальна есім чи регіональна.

6. Потрібен запит на реалізацію покупки через STRIPE. Процес покупки через STRIPE буде виглядати наступним чином.
 - Відправка POST запиту на API з тілом: { amount: 10, currency: "USD", package_index: 1}
 - API робить createPaymentIntent і повертає мені в результаті обʼєкт { "client_secret": "clientSecret"}, цей секрет отримується в результаті
    createPaymentIntent в бібліотеці STRIPE
 - Далі на стороні мобільного додатку я використовую цей clientSecret для створення оплати.

 Посилання на статтю https://medium.com/@punithsuppar7795/integrating-stripe-payment-gateway-in-flutter-for-secure-payments-96f73295c051

 Для бекенд розробників звернути увагу на заголовок 2️⃣ Backend: Creating a Payment Intent.
